# ✨ A Magical Birthday Wish ✨

A beautiful, interactive digital birthday card built with web technologies. This project features a magical fairy-tale theme complete with smooth animations, royal crowns, floating sparkles, and a dynamic "magic wand" interaction to create an unforgettable birthday surprise.

## 🌟 Features

- **🪄 Interactive Magic Wand:** A fun button that activates the card's main surprise.
- **🎵 Sound & Light Effects:** When clicked, the magic wand **plays celebratory music** and **lights up the birthday candles** on screen.
- **👑 Fairy-Tale Design:** Beautifully stylized with thematic elements like crowns (`👑`), hearts (`💖`), and sparkling animations (`✨`).
- **📱 Mobile Friendly:** Designed to look great and scale beautifully on both mobile screens and desktop monitors.

## 📁 Project Structure

Here are the main files that make this digital card work:

```text
├── index.html   # The structural layout, texts, and magical buttons
├── style.css    # The design system (colors, layouts, and sparkle animations)
└── script.js   # The interactive logic that triggers the music and candle lighting
```

## 🛠️ How to Customize It for Someone Else

If you want to reuse this project to make a card for someone else, follow these quick steps:

1. **Clone the project to your computer:**
   ```bash
   git clone https://github.com
   cd birthday
   ```

2. **Edit the Text:**
   Open the `index.html` file using any text editor and change phrases like `"My Forever Girl 💖"` or `"Happy Birthday"` to your own personal message.

3. **Swap the Music:**
   Replace the audio file in your project folder with your own custom song if you want a different soundtrack.

4. **Deploy it Back to GitHub Pages:**
   Push your changes back up to your GitHub repository to instantly update your live link!
